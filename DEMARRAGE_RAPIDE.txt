┌─────────────────────────────────────────────────────────────────┐
│ ÉTAPE 1 : OBTENIR VOTRE CLÉ API GEMINI (GRATUIT)              │
└─────────────────────────────────────────────────────────────────┘

1. Allez sur : https://aistudio.google.com/app/apikey
2. Connectez-vous avec votre compte Google
3. Cliquez sur "Create API Key"
4. Copiez la clé (format : AIzaSy...)

⚠️ IMPORTANT : Gardez cette clé secrète !

┌─────────────────────────────────────────────────────────────────┐
│ ÉTAPE 2 : INSTALLATION (Windows)                               │
└─────────────────────────────────────────────────────────────────┘

# 1. Décompressez le fichier ZIP téléchargé

# 2. Ouvrez PowerShell dans ce dossier (clic droit > "Ouvrir dans le terminal")

# 3. Installez Python si nécessaire :
https://www.python.org/downloads/

# 4. Installez les dépendances :
pip install -r requirements.txt

# 5. Configurez votre clé API :
$env:GEMINI_API_KEY="VOTRE_CLE_ICI"

# 6. Lancez le backend :
python pdf_analyzer_backend.py

# 7. Dans un AUTRE terminal, lancez le frontend :
python -m http.server 8000

# 8. Ouvrez votre navigateur sur :
http://localhost:8000

┌─────────────────────────────────────────────────────────────────┐
│ ÉTAPE 2 : INSTALLATION (Mac/Linux)                             │
└─────────────────────────────────────────────────────────────────┘

# 1. Décompressez le fichier ZIP téléchargé

# 2. Ouvrez un terminal dans ce dossier

# 3. Installez les dépendances :
pip3 install -r requirements.txt

# 4. Configurez votre clé API :
export GEMINI_API_KEY="VOTRE_CLE_ICI"

# 5. Lancez le backend :
python3 pdf_analyzer_backend.py

# 6. Dans un AUTRE terminal, lancez le frontend :
python3 -m http.server 8000

# 7. Ouvrez votre navigateur sur :
http://localhost:8000

┌─────────────────────────────────────────────────────────────────┐
│ UTILISATION                                                     │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│ PROBLÈMES COURANTS                                              │
└─────────────────────────────────────────────────────────────────┘

❌ Erreur "Module not found" 
   → Relancez : pip install -r requirements.txt

❌ Erreur "API key not valid"
   → Vérifiez que vous avez bien configuré la variable d'environnement

❌ "Connection refused"
   → Vérifiez que le backend tourne sur le port 5000

❌ L'upload est très lent
   → Compressez vos PDFs avec : https://www.ilovepdf.com/compress_pdf
